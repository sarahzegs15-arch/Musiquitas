# 🎹 Animalitos músicos

Juego musical para bebés (2–3 años) para iPad con iOS 12.5.x. Funciona **sin internet** una vez instalado. Fondo oscuro y colores suaves para cuidar sus ojitos.

## Instalar
Sube **todo el contenido de esta carpeta** a tu repositorio de GitHub Pages (reemplazando los archivos anteriores), abre la dirección en Safari con wifi, espera que carguen los animalitos y usa **Compartir → Añadir a pantalla de inicio**. Después funciona en modo avión.

## Instrumentos (menú de la izquierda, se desliza)
🦄 Piano · 🐱 Arpa · 🐥 Xilófono · 🐶 Tambor · 🐘 Trompeta · 🦁 Guitarra

Todas las notas pertenecen a la misma escala (pentatónica de Do), así que **todo lo que toque suena armónico**. Un fondo suave de acordes aparece mientras toca, y a veces se añade una segunda nota de armonía.

## Papás
Arriba a la derecha (mantener ~1 s): 🔈 silenciar · 🔄 volver al primer instrumento.
Si cambias algo, sube la versión en `sw.js` (`animalitos-musica-v2`…).
